# Jipan Chakma — Portfolio Website

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files
- `index.html` — page content and project links
- `styles.css` — responsive dark-premium visual design
- `script.js` — mobile navigation, reveal effects and current year
- `assets/jipan-chakma.jpg` — supplied profile photo
- `assets/Jipan-Chakma-CV.pdf` — supplied CV download

## Publish with GitHub Pages
1. Create a **public** GitHub repository named exactly `jipanchakma.github.io`.
2. Upload all files and folders in this package to the repository's root (not inside an extra nested folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment to finish. Your site address should be `https://jipanchakma.github.io/`.

GitHub's official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
