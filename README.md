# Jipan Chakma — Responsive Portfolio

A polished, responsive single-page portfolio built with semantic HTML, CSS and vanilla JavaScript for GitHub Pages.

## Included
- `index.html` — page structure, metadata and portfolio content
- `styles.css` — responsive dark-premium design and mobile breakpoints
- `script.js` — accessible mobile navigation, reveal effects and dynamic footer year
- `assets/jipan-chakma.jpg` — supplied profile photo
- `assets/Jipan-Chakma-CV.pdf` — supplied CV download

## Publish with GitHub Pages
1. Create a **public** repository named exactly `jipanchakma.github.io`.
2. Extract this ZIP and upload its contents (including `assets` and `.nojekyll`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.
6. After deployment completes, visit `https://jipanchakma.github.io/`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
